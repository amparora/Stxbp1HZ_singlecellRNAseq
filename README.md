# Stxbp1HZ_singlecellRNAseq

Code accompanying the manuscript

## Single cell RNA-sequencing reveals neuron type-specific vulnerabilities in a model of STXBP1-related disorder
Roig Adam, Amparo;van Berkel, Annemiek A.; Vanheusden, Matthew; Bast, Lisa; Smit, August B; Sullivan, Patrick F.; Hjerling-Leffler, Jens; Verhage, Matthijs

Pubication available at https://www.nature.com/articles/s41380-026-03869-w

Raw and processed data available from GEO accession number [GSE293659](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE293659).

## Notes
- Scripts contain application of already developed tools to the cited dataset and no original software.
- Numbering in folders and script indicate run order.
- Note that package updates may change the usage of some functions over time as well as specific computing environments may require adaptation of the code for proper reproducibility.
- Code distributed as-is without any guarantee of support to run the code in alternative environments.
